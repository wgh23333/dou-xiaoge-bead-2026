# 豆小格拼豆生成器

这是一个纯前端静态网页，可通过 GitHub Pages 等静态托管服务部署。

## 当前功能
- 图片转拼豆图纸
- 文字转拼豆图纸
- 二维码转拼豆图纸（二维码组件通过 CDN 加载，需要联网）
- 调整图纸宽度、颜色上限和网格显示
- 统计珠子数量、颜色种类及 RGB 用量
- 下载 PNG 图纸
- 闲鱼购买入口：搜索卖家 ID `wgh23333333`

## 部署
网站入口文件为 `index.html`。本项目不需要构建步骤，静态托管时将仓库根目录作为发布目录即可。

## 当前限制
这是纯前端原型：图片在用户浏览器本地处理，不会上传到服务器；目前没有在线卡密校验、支付、订单数据库或管理后台。闲鱼入口仅引导买家搜索卖家 ID，不会自动发卡。

中国大陆访问体验取决于所选托管平台及网络环境。无自有域名、无备案且零预算时，不能保证长期稳定的大陆访问地址。
