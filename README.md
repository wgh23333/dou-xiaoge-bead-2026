# 豆小格拼豆生成器

这是一个纯前端静态网页，可通过 GitHub Pages 等静态托管服务部署。

## 当前功能
- 图片转拼豆图纸
- 文字转拼豆图纸
- 二维码转拼豆图纸（二维码组件通过 CDN 加载，需要联网）
- 调整图纸宽度、颜色上限和网格显示
- 统计珠子数量、颜色种类及 RGB 用量
- 下载 PNG 图纸
- 导出图纸 CSV 和采购用量清单
- 色号搜索（色号、颜色名、HEX）
- 自定义颜色（页面内输入 HEX，加入豆小格基础色板）
- 闲鱼购买入口：搜索卖家 ID `wgh23333333`

## 本次完善
- 用量清单按数量从多到少排序，CSV 字段包含品牌、色号、颜色名、HEX 和数量，并正确处理特殊字符。
- 远程色库加载时校验数量和 HEX 格式；Artkal 透明色的 8 位 HEX 会按屏幕预览取 RGB 前 6 位。
- Artkal A 186 继续标注为图片采样参考值，不代表厂商官方 RGB。
- 新增二维码图纸入口：输入网址或文字后在浏览器本地生成二维码，再按当前色板转换为拼豆图纸。

## 部署
网站入口文件为 `index.html`。本项目不需要构建步骤，静态托管时将仓库根目录作为发布目录即可。

## 当前限制
这是纯前端原型：图片在用户浏览器本地处理，不会上传到服务器；目前没有在线卡密校验、支付、订单数据库或管理后台。闲鱼入口仅引导买家搜索卖家 ID，不会自动发卡。

中国大陆访问体验取决于所选托管平台及网络环境。无自有域名、无备案且零预算时，不能保证长期稳定的大陆访问地址。
